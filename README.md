# ofpetrial-ts

TypeScript port of the [ofpetrial](https://github.com/DIFM-Brain/ofpetrial) R package (v0.1.3) — design and diagnose on-farm experimental trials, in the browser, Node ≥ 20, and Deno (Supabase Edge Functions).

> **Status: under construction.** This repository is being built task by task from the OpenSpec change in [`openspec/changes/port-ofpetrial-ts/`](openspec/changes/port-ofpetrial-ts/). The full API documentation lands with the first release.

## What it does

- **Trial setup** — `prepPlot`, `prepRate`: machine parameters and trial rates (imperial and metric, strictly equal support)
- **Plot layout** — `makeExpPlots`: subdivide a field boundary into experimental plots aligned on an AB-line (all math in UTM, GeoJSON in/out)
- **Rate assignment** — `assignRates`, `assignRatesConditional`, `addBlocks`, `changeRates`: randomized rate designs (`ls`, `str`, `rstr`, `rb`, `ejca`, `sparse`), seedable RNG
- **Diagnostics** — `checkAlignment`, `checkOrthoInputs`, `checkOrthoWithChars`: tabular quality checks matching the R outputs
- **Machine file export** — `writeTrialFiles`: zipped Shapefile, GeoJSON, and ISOXML (ISO 11783-10, beta)

## Parity with R

Every ported function is validated against golden-master fixtures generated by ofpetrial 0.1.3 itself, with a bi-runtime test suite (R testthat + TypeScript vitest sharing the same JSON test cases) and ≥ 95 % R code coverage of the ported scope. See [`openspec/changes/port-ofpetrial-ts/specs/r-parity-harness/spec.md`](openspec/changes/port-ofpetrial-ts/specs/r-parity-harness/spec.md).
